# Nexus Media Downloader

Nexus Media Downloader is a high-performance Flutter application designed to simplify downloading media from various platforms, including KingsChat and CeFlix. Developed by **Qubators TechLabs**, it offers a seamless, glassmorphism-inspired UI and support for multiple media types.

## Features

- **Multi-Platform Support**: Extract and download media from KingsChat, CeFlix, Facebook, and more.
- **Multiple File Handling**: Automatically detects and lists all media items found in a single link.
- **Visual Previews**: View media thumbnails before downloading.
- **Smart Type Detection**: Accurately distinguishes between images and videos.
- **Gallery Integration**: Saves media directly to your device's gallery with proper permission handling.
- **Connectivity Awareness**: Notifies users of internet status to ensure reliable downloads.
- **Modern UI**: Clean and intuitive design using the **Plus Jakarta Sans** font family.
